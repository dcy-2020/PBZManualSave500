# 500 Manual Save Slots v1.0.0

[Nexus Mods page](https://www.nexusmods.com/phantombladezero/mods/1080) · [中文说明](https://github.com/dcy-2020/PBZManualSave500/blob/main/README.zh-CN.md)

Raise Phantom Blade Zero's normal manual save limit from **20 to 500**. Keep more progress milestones with the game's existing save and load menus.

**Tested in game with 27 manual saves working normally.** Steam build 26367565 / PBZModLoader 2.1.0.

Install [PBZModLoader 2.1.0](https://github.com/KintaroModding/phantombladezero_pbzmodloader/releases/tag/v2.1.0), then extract **PBZ-Manual-Save-500-v1.0.0.zip** into your game root. The installed entry should be:

`ProjectPBZ/PBZModLoader/mods/PBZManualSave500/main.js`

Start the game normally. The manual save menu shows `/500`. Automatic saves and Nightmare slots keep their original behaviour. Close the game before installing, removing or updating this mod.
